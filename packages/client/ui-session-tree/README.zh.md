# ui-session-tree

[English](README.md) | 中文

会话树插件的浏览器端。它在会话顶部的视图栏（`conversation.view`，位于 Chat
和 Trajectory 之后）注册一个 **会话树** 标签，展示当前会话的合并谱系图；
不会渲染于输入框上方，也不会创建独立页面。

- 该标签会把当前谱系中所有非 subagent 会话合并为一张图。会话层拓扑来自响应式原生会话列表，节点层拓扑来自只读的 `sessionTree.list` 请求：每个谱系会话先读取一次，此后只在它自己的列表行变化时再读取（每秒至多一次，每个会话同时最多一个请求）。子会话复制来的节点会与父会话的整棵树比对：id、事件 seq、时间戳和摘要全部一致且父节点同样共享时才视为同一节点，因此无论哪一方的游标停在哪里，复制部分都保持合并。分支独有节点保留带会话标识的唯一身份。
- 图上方的分支概览以缩进树列出谱系中的每个会话，并标出它在第几轮后分出、新增了几轮以及它的第一条新提问。选中某个会话后，图只显示它的历史（复制来的部分加上它自己的节点）；点头部的标签可回到全部分支。有其他历史从某行离开时，该行会显示分出标记：合并视图下点击跳到该分支，聚焦时点击则切换到该分支。每个会话固定一种颜色，用于色块和图中的节点圆点。
- 「对话 / 全部」切换会折叠工具调用、推理和注入的上下文，只保留用户输入和助手正文，每条回复注明折叠了几次工具调用。选择保存在 `localStorage` 中；切换时视图顶部的那一行保持在原位置。
- 节点上的 ⑂ 会从该节点创建当前项目下的独立会话副本；内联分支标题取该节点上一条用户消息。`/clone` 直接把当前会话完整复制到同项目的新会话。
- 分叉点显示主会话/分叉/克隆徽标、会话标题和可选分支名。当前打开的会话及其路径保持高亮。点击节点时，若当前会话包含该节点就在当前会话内跳转，否则先打开写入该节点的会话再跳转。会话分支和节点子树都可独立收起。单个会话加载失败只会显示局部占位，不影响图的其余部分。
- 固定 44px、五轨道的图形栏使用纵向轨道和曲线连接线表达分支，视觉参考 IDEA Git Log：后续子节点从分叉行拐出，连线会延伸覆盖较高的行。轨道数量有界并复用，树深度不会转化为 margin/padding，因此不会横向无限增长。行按组渲染，屏幕外的组跳过排版，数千节点的谱系也能流畅滚动和收起。
- 左侧垂直居中的展开/收起按钮控制子树显示；分支头、角色、分支名、摘要、刷新和一键 fork 全部复用 Harness 的 `--dsw-alias-*` 原生主题 token，自动适配明暗主题。

## 会话列表内联分叉菜单

从节点 fork 创建分叉会话后，叠加式 `shell.overlay` 条目
（`session-tree-branches`）会把可折叠菜单直接挂载到原父会话的原生列表项
之后。这是左侧会话列表中的菜单，与会话树标签里的合并图相互独立。分叉
子会话在菜单内以纵向连接轨道、转肘接点和逐级展开/收起控件展示；子会话
标题取选中节点上一条用户消息。分叉落地时菜单自动展开，并跟随响应式会话
列表更新，新分支出现无需刷新浏览器。

实现上只做表现层：分叉数据与父子关系完全来自官方原生分叉 API
（`ctx.sessions.fork` 会以 `parentId` 写入子会话），菜单的级联结构纯粹从
该响应式列表推导。子会话以内联方式展示时，其原生列表项会隐藏，并在菜单
卸载时恢复。一个很小的 UI 层标注注册表（`fork-lineage.ts`，持久化到
`localStorage`）只负责标记哪些子会话来自节点 fork——因此 `/clone` 会话与
普通会话不会进入菜单，保持原有侧边栏展示不变。`sidebar` 槽位本身保持
原样：它是单占位槽（替换会连带移除官方 workspace/settings 座位），叠加式
`shell.overlay` 条目即内联渲染的正确落点。

## 组合

```yaml
- id: ui-session-tree
  name: '@robiteame/dsh-client-ui-session-tree'
```

官方独立 Bundle 已经同时提供 Host 端两个扩展包和本浏览器包。打补丁的源码
集成还需 `dev/harness.patch` 中的 Host 端两个扩展包。

## 模型体验

本包只负责展示。它读取、导航共享 SessionTree；面板内容不会进入模型上下文，也不会改变 KV Cache 前缀。
